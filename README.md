# 声线练习室（React 应用）

`src/` 是另一个独立应用：声线练习室。开发预览：`npm run dev` 后访问
`/sound-lab.html`；生产构建：`npm run build`（同时输出两个入口）。

## 静音裁切（侧栏视图）

在侧栏点击“静音裁切”进入。每条录音登记四要素：句子、原始时长、静音区间、
保留区间；有效音段由静音区间在时间轴上的补集自动推导。

预览校验（任一不满足即拒绝预览，输入原值与既有数据均保留）：

1. 区间越界：区间非法或落在 `[0, 原始时长)` 之外；
2. 区间重叠：拟保留区间之间相互重叠；
3. 裁切后不足 3 秒；
4. 覆盖全部有效音段（等于没有裁掉任何有声内容）。

- 同一句子至多一个待确认裁切；再次预览会替换它。
- 确认后追加一个不可变新版本，旧录音/旧版本仍可在“版本记录”中查看。
- 撤销只删除最近一次已确认裁切版本，回到上一版本；有待确认项时禁用。
- 录音、裁切版本与待确认项均持久化在 `localStorage`，刷新后保持一致。

分层（互不混入）：

- `src/crop/types.ts` — 数据模型；
- `src/crop/logic.ts` — 判定层（纯函数：区间运算、四条校验规则）；
- `src/crop/store.ts` — 存储层（localStorage、纯状态转移、React 订阅）；
- `src/crop/CropView.tsx` — 页面层（只读订阅 + 交互，不重写规则）。

`npm test` 运行无额外依赖的判定/存储冒烟测试（40 项）。
